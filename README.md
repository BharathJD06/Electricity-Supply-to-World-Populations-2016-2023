## 📌 Project Overview
A geospatial and temporal analysis of global electricity supply coverage, exploring how access to electricity has evolved across world populations from 2016 to 2023. Interactive Power BI dashboards visualize country-level and regional trends.

## 📊 Key Analysis
- Country-level electricity access rates (2016–2023)
- Regional comparison: developed vs. developing nations
- Year-over-year progress in electrification
- Population without electricity access — trend analysis
- Correlation between GDP and electricity access rates

## 💡 Key Insights
- Significant electrification progress in Sub-Saharan Africa (2016–2023)
- Identified regions still significantly below global access averages
- Visualized the relationship between economic development and energy access
